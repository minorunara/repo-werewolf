# [Experimental] REPO-Werewolf [BETA]

This is a work-in-progress beta version of [REPO Werewolf](https://thunderstore.io/c/repo/p/sukunabikona/REPO_Werewolf/).<br>
It hasn't been thoroughly tested yet, so you may run into bugs.<br>
This version is mainly intended for playtesting with the developer's own group, so I don't recommend using it for regular play. If you decide to use it anyway, make sure not to enable it in the same profile as the stable `REPO_Werewolf` package.<br>
Everyone in the lobby must be using the same version.<br>


これはREPO人狼（https://thunderstore.io/c/repo/p/sukunabikona/REPO_Werewolf/）の開発中のベータ版です。<br>
まだ十分にテストされたとは言えず、不具合が起きる可能性があります。<br>
基本的に開発者の身内でテストプレイするために使うものなので使用することはお勧めしませんが、何かの理由で使う場合は安定版の `REPO_Werewolf` と同じプロファイルで同時に有効化しないでください。<br>
ロビーの全員が同じバージョンを使用する必要があります。<br>
